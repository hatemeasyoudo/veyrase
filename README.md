# Veyrase — GitHub, Supabase и Vercel

В проекте есть англоязычная витрина, галерея, корзина, заявки на заказ и возврат,
ссылки на Instagram и TikTok и защищённая админка на русском языке.

## 1. GitHub

Распакуйте ZIP. Создайте личный репозиторий на GitHub и загрузите **содержимое
распакованной папки** через **Add file → Upload files → Commit changes**.
Файлы `package.json`, `vercel.json` и папки `api`, `public`, `server`,
`supabase` должны быть в корне репозитория.

## 2. Supabase

1. Создайте проект и откройте **SQL Editor → New query**.
2. Скопируйте содержимое файла `supabase/schema.sql`, вставьте его целиком и
   нажмите **Run**. Таблицы создаются в отдельной схеме `veyrase`.
   Затем отдельно запустите `supabase/checkout.sql` для оформления заказа и оплаты.
3. Вверху проекта нажмите **Connect**, выберите **Transaction pooler** и
   скопируйте PostgreSQL URI. Подставьте в URI пароль базы, который задали
   при создании проекта. Если в пароле есть специальные символы URI,
   например `@` или `/`, закодируйте их в процентном формате.

## 3. Vercel

1. Откройте **Add New → Project**, выберите репозиторий GitHub и нажмите
   **Import**. Для Framework Preset используйте **Other**. Конфигурация
   сборки и маршрутов уже указана в `vercel.json`.
2. В разделе **Environment Variables** добавьте две переменные для
   **Production**.

   | Имя | Значение |
   | --- | --- |
   | `DATABASE_URL` | PostgreSQL URI из Supabase **Transaction pooler** |
   | `ADMIN_PASSWORD` | Ваш уникальный пароль для админки, от 20 символов |

   Значения задайте в Vercel. В репозитории хранится только пример `.env.example`.
3. Нажмите **Deploy**. Откройте адрес `*.vercel.app`, добавьте товар в корзину
   и проверьте форму заказа. Админка открывается по пути `/admin`.
   Имя пользователя — `admin`.

## 4. Домен veyrase.store

Когда витрина, формы и админка работают на `*.vercel.app`, добавьте
`veyrase.store` в **Vercel → Project → Settings → Domains**. Vercel покажет
записи DNS для вашего проекта. В Cloudflare при переключении отключите старую
привязку Worker для этого домена и сразу внесите записи Vercel в **DNS → Records**.
Выберите **DNS only** (серое облако). Дождитесь подтверждения домена и HTTPS.

## Заказы и статистика

Для действующего магазина сначала запустите только `supabase/checkout.sql`
в **Supabase → SQL Editor → New query**, затем загрузите файлы обновления
в GitHub. Миграция добавляет поля к существующей таблице заказов и сохраняет
прежние данные. Её можно запустить повторно.

Покупатель вводит контакты и адрес доставки, получает номер заказа и сумму
в USD. После перевода по [ссылке Revolut](https://revolut.me/kosex) он возвращается
к заказу и указывает имя плательщика и номер перевода, если он доступен.
Кнопка **View latest order** в корзине позволяет снова открыть последний
заказ на этом устройстве.

В админке откройте **Заказы**, раскройте **Адрес доставки** и сверьте
поступление в Revolut по номеру заказа, сумме и имени плательщика. Для нового
заказа выберите **Оплачено** и введите уникальный ID полученной операции.
Один перевод можно привязать к одному заказу. Покупка учитывается в конверсии
после подтверждения. Для прежних заказов доступно прежнее ручное подтверждение.

Форма в **Returns** сохраняет заявку во вкладке
**Возвраты**. Статистика начинает собираться после публикации. Для ссылок в
постах и рекламе используйте, например, `?utm_source=instagram&utm_medium=social`.
