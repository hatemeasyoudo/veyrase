# Цены через админку

Основа: текущий main репозитория hatemeasyoudo/veyrase, 751e862.

Установка:
1. В Supabase → SQL Editor → New query вставьте содержимое supabase/pricing.sql и нажмите Run. Это добавляет таблицу настроек, не удаляет статистику и заказы. Повторный запуск не сбрасывает сохранённые цены.
2. Распакуйте архив. Загрузите его содержимое в корень GitHub-репозитория с заменой файлов и сохранением папок public, server, supabase, docs. Загрузите также vercel.json. Сам ZIP загружать не нужно.
3. Дождитесь успешной публикации Vercel. Откройте /admin и обновите страницу. Вкладка «Цены» → стоимость браслета / доставки в USD → «Сохранить цены».

Диапазон цены: 0.01–10000 USD, доставки: 0–10000 USD. Доставка за заказ, 0 означает бесплатно. Валюта остаётся USD. Суммы сохраняются в целых центах.

Сайт загружает актуальные цены при открытии страницы и перед созданием заказа. Если цены изменились во время оформления, покупателю показывается новая сумма и требуется повторная отправка. Созданные заказы и ссылки на оплату сохраняют прежнюю сумму. Изменения в админке не требуют нового деплоя.

До установки SQL магазин использует прежние $40 + $20; вкладка цен объясняет необходимость миграции. При сетевой ошибке загрузки цен новый checkout блокируется, неверные суммы не отправляются.

Проверено: интеграционный тест PostgreSQL/PGlite — авторизация, валидация сумм, безопасный повтор миграции, бесплатная доставка, старые суммы и повтор запроса заказа, отказ при устаревшей цене. DOM-проверка сохранения формы админки и подстановки цены/доставки на витрине.

Рабочая Supabase и деплой не изменялись: доступа к ним в этой сессии нет.
